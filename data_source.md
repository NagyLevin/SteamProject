### Dataset Source and Background

The dataset selected for this project is **Steam Video Games**, published by Tamber on Kaggle.

The dataset contains approximately 200,000 user-game interactions collected from publicly available Steam data. These interactions describe game ownership or purchase-related records and recorded playtime.

The dataset was originally published in the context of video game recommendation systems. In this project, it will instead be used to investigate user behavior and identify potential player segments through clustering.

The dataset is relatively old, and its exact collection period, sampling methodology, and detailed data provenance are not fully documented. These limitations will be considered when interpreting the results.

**Source:** Tamber, *Steam Video Games*, Kaggle.
