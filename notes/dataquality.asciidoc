
= Data Quality Assessment

== Missing Values

I created the `get_missing_values()` function to examine
the number and percentage of missing values in each column.

The function uses `df.isna().sum()` to count missing values
and `df.isna().mean() * 100` to calculate their percentages.

=== Results

All five columns contain 0 missing values (0.0%).

=== Interpretation

No missing values were detected in the original dataset.
Therefore, no missing value imputation or row removal
is required at this stage.

However, the absence of missing cells does not guarantee
that every purchase record has a corresponding play record.
This relationship will be examined separately.

== Duplicate Records

I created the `get_duplicates()` function to
identify fully duplicated rows in the original dataset.

The function uses `df.duplicated().sum()` to count
records that are identical to previously occurring rows.

It also calculates the percentage of duplicate
records relative to the total dataset size.

The purpose of this analysis is to identify possible
redundant records that could affect the accuracy later.

The dataset contains 707 fully duplicated rows out of
200,000 total records, representing approximately 0.35%
of the dataset.

The duplicated rows will first be examined to determine their behavior types and whether they represent redundant information.

To investigate the duplicates further, I created the
`inspect_duplicate_records()` function, which uses
`value_counts()` to examine their distribution
across behavior types.

All 707 fully duplicated records belong to the
`purchase` category. No fully duplicated `play`
records were detected.

Further inspection showed that some purchase
records appear multiple times for the same user
and game.

Examples include games from the Grand Theft Auto
series and Sid Meier's Civilization IV.

One possible explanation is that the duplicates
were introduced during the original data collection
or processing procedure. However, the exact cause is unknown for me.

I used `duplicated(subset=["user_id", "game_name"],
keep=False)` to identify multiple play records
associated with the same user and game.

The analysis identified 24 matching play records.

Unlike the previously identified 707 fully duplicated
purchase records, these play records contain different
playtime values.

For example, one user has two recorded playtime
values of 135.0 and 2.0 hours for
Sid Meier's Civilization IV.

Summing the values could potentially overestimate
total playtime if the measurements overlap.

I will keep the bigger number for each user.
